# Flutter Base Template, version 0.1.0

This is the starting point for our future mobile and web apps. Instead of building the same basics every time, we copy this template and begin with a working app.

## What's included

**Ready-made screens**
- Welcome screen shown while the app opens
- Short intro pages for first-time users
- Sign in, create account and forgot password
- Home, profile, edit profile and settings
- About, terms of service and privacy policy
- Friendly "page not found", "you're offline" and "back soon" screens

**Look and feel**
- Modern design with light and dark modes
- Bottom menu on phones and a side menu on larger screens
- Consistent buttons, forms, messages and pop-ups across the app

**Forms that behave the same everywhere**
- Ready-made fields for email, password, phone, dates, codes, search and more
- One shared set of rules for what counts as valid, with clear error messages
- Buttons that can't be pressed twice by accident, and a warning before leaving a screen with unsaved changes

**Safe handling of problems**
- A banner appears when the internet drops
- Clear messages instead of technical errors
- Signed-out users are guided to sign in, and are brought back to where they were headed afterwards

**Tools for the team**
- One command builds the app and raises the version number automatically
- Separate commands for minor and major releases
- Builds for Android, iPhone, web and computers, including smaller Android files for each phone type
- Step-by-step guides in the `docs` folder
- Instructions for AI coding assistants, so they follow our standards

## What to know before using it

- **Sign-in is a demo for now.** Any email and password work in test versions. A real app needs a real account system behind it.
- **Legal pages are placeholders.** Replace the terms and privacy text before releasing to the public.
- **The design hasn't been reviewed on real phones.** Automated checks confirm every screen loads without layout errors, but someone should look at it on a device.
- **Not included yet:** crash reports, usage analytics, other languages, push notifications, offline saving of data, and account deletion. App stores require account deletion if people can create accounts.
